# 📝 To-Do List

A simple and interactive To-Do List web application built using HTML, CSS and JavaScript.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
